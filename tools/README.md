# Operator tools

- [1Password migration and verification](migrate_1password/README.md): combine 1PUX exports with the official iOS passkey transfer, upload files and verify source-to-destination content while leaving 1Password intact.

- [Encrypted vault backup and recovery](../docs/backup.md): live capture, single-latest retention, opt-in scheduling, pause/retarget and fresh-vault recovery. Implemented by `scripts/vault_backup.py` and `scripts/install_vault_backup.py`.
